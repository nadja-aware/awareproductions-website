# awareproductions.org

Website of AWARE Productions. Plain HTML, CSS and JavaScript, published with GitHub Pages.

- `index.html` – the homepage
- `impressum.html`, `privacy.html` – legal pages
- `img/`, `video/` – photos and the header aftermovie (compressed for web)
- `fonts/` – Archivo and Instrument Serif, self-hosted (SIL Open Font License)
- `CNAME` – connects the site to awareproductions.org
